# SUNOBOOM — Творческая лаборатория

**Версия:** 0.5 · браузерный прототип.

SUNOBOOM — каталог музыкальных жанров, генератор идей и конструктор промптов для Suno.

## Основная навигация
1. Главная
2. Энциклопедия жанров
3. Идеи песен и Idea Lab
4. Suno Studio
5. **Личный кабинет**

## Личный кабинет
- **Мои проекты** — артисты, EP, альбомы, заметки и треклисты
- **Избранное** — сохранённые жанры, идеи и промпты
- **Профиль** — локальное отображаемое имя
- **Резервные копии** — импорт и экспорт JSON

Личный кабинет в версии 0.5 — это удобная организация персональных данных, **не регистрация и не защищённая учётная запись**. Данные хранятся в браузере (localStorage), автоматически не синхронизируются между устройствами. Чтобы сохранить их при смене устройства, используйте резервную копию.

## Запуск
Основной файл сайта — `index.html` в корне репозитория. Для GitHub Pages используйте Source: Deploy from a branch, Branch: main, Folder: /(root).

Адрес прототипа: https://nick-osinskiy.github.io/SUNOBOOM/

## Безопасность и ограничения
Этот репозиторий и GitHub Pages опубликованы в режиме **Public**: исходники и сайт доступны другим людям. В приложении нет серверной авторизации, системы приглашений или разграничения доступа. Для закрытой мастерской потребуется отдельный защищённый вход.

Idea Lab работает офлайн на сюжетных заготовках, не через AI API. Suno Studio подготавливает промпты и не вызывает Suno API. Проект независим от сервиса Suno.
