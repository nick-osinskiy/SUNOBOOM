# SUNOBOOM — Творческая лаборатория

**Версия:** 0.98 · браузерная творческая мастерская.

SUNOBOOM — каталог музыкальных жанров, генератор идей и конструктор промптов для Suno.

## Vue 3 — обзор жанра и расширенные исполнители (v0.98)

- «Обзор» переведён в отдельный Vue-компонент с информацией о звучании, инструментах, тематике, музыкальных ориентирах и идеях.
- Раздел «Исполнители» теперь использует Vue: мировая/русскоязычная сцены, поиск по артистам и произведениям, фильтры по роли в жанре.
- Сохранены расширенная база исполнителей, полные профили и избранное, без дублирования коллекций или изменения пользовательских данных.
- «Идеи песен» и «Промпты Suno» пока используют проверенные генераторы SUNOBOOM.
- Сборка Vite и браузерные тесты Chromium для десктопа и телефона успешно пройдены.

## Vue 3 — страница музыкального жанра (v0.97)

- На Vue перенесены шапка карточки и вертикальное меню «ЖАНР-НАВ».
- Четыре раздела карточки переключаются реактивно: обзор, идеи песен, промпты Suno и исполнители.
- Содержимое разделов пока формируют существующие функции SUNOBOOM: так сохранены русскоязычные исполнители, готовые идеи и все ранее добавленные материалы.
- Сохранены обработчики «В избранное», «Создать в Suno» и «Назад» с восстановлением ранее введённого поиска.
- Проверено в Chromium на десктопе и мобильном экране, включая функциональные действия.
- Прежняя HTML-разметка остаётся резервной при недоступности Vue.

## Vue 3 — реактивная Академия (v0.96)

- Vue управляет поиском, фильтрацией, списком музыкальных семейств, их раскрытием и счётчиками результатов.
- Сохранён существующий алгоритм приоритета поиска SUNOBOOM, включая русскоязычные названия, исполнителей и поиск «ска».
- Иерархия религиозной музыки полностью отображается на Vue; исходные справочники, пользовательские данные и карточки жанров не заменены.
- Десктопные и мобильные тесты Chromium прошли успешно до включения новой сборки.
- Прежняя HTML-версия Академии сохраняется как резервная при сбое Vue; миграции пользовательских хранилищ не требуется.

## Vue 3 — карточки Академии (v0.95)

- Карточки музыкальных жанров внутри Академии перенесены на Vue 3 и получают данные непосредственно из действующего массива `GENRES`.
- Сохранены прежние семейства жанров, иерархия религиозной музыки, умный поиск и переходы в существующие карточки жанров.
- Проверено в Chromium на мобильной и десктопной ширине: поиск «ска», переход в карточку и наличие вложенных каталогов.
- Vue-модуль публикуется только после успешных проверок GitHub Actions. Если загрузка Vue не удаётся, исходные карточки остаются работоспособными.

## Vue 3 навигация (v0.94)

- Боковое и мобильное меню используют собранный Vue-модуль из `dist/vue/`; названия разделов, включая «Мастер», берутся из существующей навигации.
- Сборка прошла GitHub Actions с браузерными проверками Chromium для десктопа и мобильного размера.
- Все страницы, прежний роутер `go()`, локальные хранилища и музыкальные инструменты работают на существующей архитектуре.
- Если Vue-модуль недоступен, исходное меню продолжает работать; переключатель реализации — метатег `sunoboom-vue-nav` в `index.html`.
- Для отката достаточно убрать метатег (или изменить `content="enabled"`), без изменения персональных данных или настроек GitHub Pages.

## Интеллектуальный аудитор промптов (v0.91)

Встроен в **Suno Studio** (после конструктора и визуального аранжировщика). Проверяет текущий промпт при изменении настроек, также принимает отдельно вставленный текст. Из раздела **Личный кабинет → Мои промпты** доступна кнопка **«Проверить этот промпт в аудиторе»** — она переносит введённый текст для проверки без сохранения и изменения исходного материала.

- Проверяет ограничение **1000 символов** и предупреждает о приближении к лимиту.
- Находит точные повторения указаний, избыток фрагментов/слов, разные значения BPM и отдельные явные противоречия (например, одновременное «no choir» и требование хора).
- Сопоставляет текст с выбранным жанром Академии и его типичным диапазоном BPM, при этом жанровые смешения считает возможным творческим приёмом, а не обязательной ошибкой.
- Показывает **ориентировочную эвристическую оценку 0–100**, замечания и понятные рекомендации.
- По кнопке предлагает сокращённый вариант: удаляет точные дубликаты и, только при превышении лимита, некоторые второстепенные фразы с явным перечнем удалений. Пользователь может вручную править предпросмотр и только затем подтвердить копирование.

Аудитор **локальный и работает по правилам**, а не на базе Gemini: **Gemini API ещё не подключён**. Он не предсказывает качество генерации. Оригинальные промпты, исходные карточки и настройки Studio не изменяются автоматически; предложения не сохраняются и не подменяют исходник без отдельного действия.

## Мастер (создан в v0.90, переименован в v0.92)

Новый полноценный раздел основного сайта: **идея → текст → аранжировка → генерация → прослушивание → релиз**. Доступен в главном меню и личном кабинете, а также из существующих карточек идей, паспортов и песен.

- Рабочая карточка создаётся на основе существующей идеи, песни или паспорта, либо вручную; уже связанная песня открывается повторно, без дублей.
- Подключаются **оригинальные** проекты, идеи, идеи Idea Lab, промпты, паспорта треков и песни — без копирования или изменения исходных материалов.
- Для каждого из 6 этапов можно выбрать «Не начато», «В работе» или «Готово»; есть процент завершённости и подсказки о наличии материалов.
- Сохраняются продюсерские заметки и хронология изменений внутри центра.
- Аранжировку из действующей Suno Studio можно явно сохранить как снимок **для конкретной песни** и позже восстановить. Восстановление требует подтверждения, поскольку заменяет общий черновик Studio.
- Из центра можно напрямую открыть существующий редактор текста, аранжировщик, промпты, паспорт или карточку с MP3/M4A/WAV и A/B-сравнением.

Рабочие карточки и снимки аранжировок входят в локальный файл JSON-резервной копии по ключу `sunoboom-v1`. **Сами аудиофайлы хранятся отдельно в IndexedDB**, и JSON-экспорт их не включает. Генерация аудио выполняется вне SUNOBOOM, поскольку Suno API к этому прототипу не подключён. История фиксирует изменения, совершённые в разделе «Мастер»; изменения исходных файлов в других разделах не добавляются в неё автоматически.

## Личный кабинет
- **Мои проекты** — артисты, альбомы, EP, заметки и треклисты
- **Мои идеи** — ручное создание, редактирование и удаление идей; идеи, сохранённые из Idea Lab и каталога; перенос идеи в Suno Studio
- **Мои промпты** — ручное добавление, редактирование, копирование и удаление промптов; сохранённые промпты из Suno Studio, до 1000 символов
- **Избранное** — любимые жанры, идеи и промпты
- **Мой профиль** — локальное отображаемое имя
- **Резервные копии** — экспорт и импорт JSON со всеми сохранёнными материалами

## Тексты песен, метатеги и усилители (0.7)
В разделе **Личный кабинет → Мои идеи** теперь можно вставить полный текст песни в поле **Оригинальный текст** и нажать **Создать теги и усилители**.

Разметчик умеет:
- распознавать заголовки «Куплет 1», «Припев», «Бридж» и английские теги `[Verse]`, `[Chorus]`, `[Bridge]`;
- добавлять указания для более мощного припева, нарастания энергии, гармоний, финального усиления и (для танцевальных треков) дропа;
- выдавать отдельный текст для поля **Lyrics** и описания для поля **Style** в Suno;
- сохранять оригинальный текст, размеченную версию и Style в одной карточке идеи; копировать Lyrics, редактировать и сохранять обратно.

Важно: текст **не переписывается**. Если разметка отсутствует, разметчик предполагает секции по абзацам — проверить распределение куплетов и припевов нужно вручную. Это локальный алгоритм, **Gemini API ещё не подключён**. Теги и подсказки описывают желаемый результат, но не гарантируют точную аранжировку в Suno.

По умолчанию нет команд на шёпот, хриплый вокал или концертный шум; гармонии добавляются только по выбору пользователя.

## Как использовать
Откройте **Личный кабинет → Мои идеи**, чтобы записать сюжет будущей песни, указать жанр и при желании строку припева.

Откройте **Личный кабинет → Мои промпты**, чтобы добавить готовый промпт для Suno, скопировать или изменить его.

В Idea Lab и Suno Studio также есть кнопки сохранения; результаты появляются в соответствующих разделах личного кабинета.

## Данные и приватность
- Хранение в браузере через `localStorage` под прежним ключом `sunoboom-v1`; данные старых версий не сбрасываются
- Резервные копии JSON позволяют вручную переносить проекты и материалы
- Нет авторизации, паролей, серверных профилей или автоматической синхронизации между устройствами
- Репозиторий и сайт GitHub Pages общедоступны; личный кабинет — локальный интерфейс, а не защищённая учётная запись
- Idea Lab работает на локальных сюжетных шаблонах, без AI API; Suno Studio готовит текст промпта, но не вызывает Suno API

SUNOBOOM — независимый прототип, не являющийся официальным продуктом Suno.
