# SUNOBOOM — приватная музыкальная мастерская

**Текущая версия:** 0.4 (прототип).

SUNOBOOM — каталог музыкальных жанров и творческая мастерская с идеями песен и промптами для Suno.

## Разделы
- Главная
- Энциклопедия музыкальных жанров
- Идеи песен и **Idea Lab** — локальный генератор идей
- Suno Studio — конструктор промптов
- Мои проекты
- Избранное

## Запуск
Всё приложение находится в `index.html` — сборка и установка библиотек не нужны. Для работы на iPhone по HTTPS этот файл можно развернуть на хостинге статических сайтов.

## Приватность и ограничения
- Репозиторий на GitHub приватный, но **публикация приложения на обычном хостинге сама по себе не ограничивает доступ**.
- В версии 0.4 пока нет регистрации, ролей и настоящего доступа по приглашениям.
- Проекты, промпты и избранное сохраняются локально в браузере (localStorage): пользуйтесь экспортом резервной копии. Между устройствами данные автоматически не синхронизируются.
- Idea Lab работает офлайн на основе сюжетных заготовок. Он не подключён к модели ИИ.
- Suno Studio готовит текст промптов, но не запускает генерацию через Suno API.

Этот репозиторий не содержит публичной лицензии. Исходники предназначены для закрытого использования владельцем.
