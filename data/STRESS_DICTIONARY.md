# Словарь русских ударений SUNOBOOM

- Источник: [zdarsch/russian-stress-marker](https://github.com/zdarsch/russian-stress-marker), версия на основе компактизированного FSA.
- Лицензия: MIT, © 2024 zdarsch. Текст лицензии: `THIRD_PARTY_LICENSES/russian-stress-marker-MIT.txt`.
- Готовый словарь `russian-stress-marker.b64` импортирован из публичного репозитория [FedorMilovanov/gb-vosk-tts](https://github.com/FedorMilovanov/gb-vosk-tts), файл `data/russian-stress-marker.bin` (без изменений бинарного содержимого, сохранён в Base64 для GitHub Pages).
- Объём: приблизительно 2 039 133 русских словоформы, бинарные данные 721 732 байта.
- Словарь загружается только после нажатия «Автоударения» и обрабатывается локально в браузере. Песенные тексты не отправляются на сервер для расстановки ударений.
- Омонимы и омографы не разрешаются по контексту. Встроенный краткий словарь и однозначные односложные слова используются как резервный вариант.
